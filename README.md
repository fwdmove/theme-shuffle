# Theme Shuffle

A 3D shell game built with Three.js. Pick a theme (🏀 Basketball, ⚽ Soccer, or 🎨 Cartoon), roll three characters, choose your favorite, and watch the dealer shuffle it under the cups. Guess the right cup to keep it. Rarer characters earn more money but get shuffled faster.

Spend your earnings upgrading the dealer: he starts as a classic noob and levels up through 8 looks (Noob → Cosmic). Each level brings better luck on rolls and fancier cups.

## Play

```bash
npm install
npm run dev
```

Controls: click/tap a cup to guess, `Space` to roll, `1` `2` `3` to pick a cup.

## Build

```bash
npm run build
```

`?shot=thumb` renders the static pose used for `public/thumbnail.png`.
